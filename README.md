# easemo

Make demos easy.

A lightweight, fully-local macOS screen + webcam recorder with post-recording
composition (overlay shape & position) and playback-speed export.

The Xcode project lives in [`easemo/`](./easemo). See
[`easemo/README.md`](./easemo/README.md) for a full description of the
architecture and how to build, run, and test the app.

## Quick start

```bash
open easemo/easemo.xcodeproj
```

Then choose the **easemo** scheme and press **⌘R** in Xcode 15+ on macOS 14+.
